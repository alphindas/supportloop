# Judge review verdicts

**The judge is not validated by a human yet.**

The folder name and the `human` field are left over from the original plan, which was a
human review. The two rounds stored here were **not** done by a person: the verdicts came
from a second-AI reviewer (ChatGPT). In each record, `human` is ChatGPT's verdict and
`judge` is the eval judge's verdict.

The `.jsonl` files are published unedited, and a test pins them by hash, so the names stay.
See the judge review section of the eval report in `reports/` for what these numbers can
and cannot show.
